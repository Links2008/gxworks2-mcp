# GX Works2 MCP 与原生工程读写调研

检索日期：2026-10-20。覆盖网页检索和 GitHub 仓库 API，检索词包括 gxworks2 mcp、
gxworks3 mcp、GXW writer、FX3U SFC encode；目录网站只用于发现，结论以原仓库为准。

| 项目 | 已核对的作用 | 本项目采用的原则 |
|---|---|---|
| [Arienax/gxworks-agent](https://github.com/Arienax/gxworks-agent) | GX Works2 工程工作台，原生程序体和容器读写，FX3U 编码观察表 | 原生源码绑定、其他流保留、元数据同步、编译缓存独立验收 |
| [coder007rahul/gxworks3-mcp-bridge](https://github.com/coder007rahul/gxworks3-mcp-bridge) | GX Works3 ST 读写、编译、写入前后校验；通过 UIA、剪贴板与键盘操作 | 学习写后核验；用户要求快速无窗口，本项目主线直接写文件 |
| [purinzan/gx3-cli-mcp](https://github.com/purinzan/gx3-cli-mcp) | 本地 GX Works3 只读分析、交叉引用、线圈追踪和往返校验 | 从指令与设备引用回答问题，不猜测未知二进制语义 |
| [monozukuri-ai/gxwlib](https://github.com/monozukuri-ai/gxwlib) | Rust/Python GXW 只读库，梯形图与结构化 POU；显式 FX/Q 地址配置 | 按 CPU 解释 X/Y，区分结构完整性与可执行语义 |
| [ito-soft-design/ladder_converter](https://github.com/ito-soft-design/ladder_converter) | PLC 梯形图转换与 CSV 样例 | 文本交换格式作为备选，不代替原生文件验收 |
| [shw98-jp/gxworks2-io-list-lab](https://github.com/shw98-jp/gxworks2-io-list-lab) | GX Works2 CSV 数据分析和 I/O 清单研究 | 作为工程清单方向参考，不宣称具备原生工程写入能力 |

对 gxworks-agent 实际下载提交 `4c456be917e67fe4091811c575690a7c17fdd28b` 检查了
`LICENSE`、`LICENSE-SCOPE.md`，二者是 Apache-2.0。搜索引擎缓存仍显示其历史专有许可，
故本次以固定提交的实际文件为依据。只复用指令编码数据表，许可与出处位于 `third-party/`。

GX Works2/3 的软件版本、PLC CPU、语言支持和图形格式不能相互套用。GX Works3 ST
剪贴板方案未被搬入本项目；原生 SFC 图形画布与 FX3U STL/RET 顺控程序分别报告。

## 官方依据

- [FX3U 硬件手册 JY997D16501](https://www.mitsubishielectric.com/dl/fa/document/manual/plc_fx/jy997d16501/jy997d16501y.pdf)：X/Y 为八进制。
- [FX3 系列编程手册 JY997D16601](https://www.mitsubishielectric.com/dl/fa/document/manual/plc_fx/jy997d16601/jy997d16601r.pdf)：SFC/STL、状态软元件及定时器规则。
- [GX Works2 简单工程手册](https://www.mitsubishielectric.com/dl/fa/document/manual/plc/sh080780eng/sh080780engaf.pdf)：梯形图和 SFC 编辑、转换操作。
- [pywin32 IStorage 实现](https://github.com/mhammond/pywin32/blob/main/com/win32com/src/extensions/PyIStorage.cpp)：原生流打开、调整大小、写入和提交接口。
