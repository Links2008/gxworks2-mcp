# 工程技能

本批增加两项项目开发辅助技能和三项三菱工程技能。技能提供工艺推理与审查方法；工程写入、原生编译、读回和真实仿真继续使用现有 MCP。

## 三项 MCP 工程技能

| 名称 | 使用场景 | 重点 |
|---|---|---|
| mitsubishi-io-planner | 新增或调整 I/O、软元件、标签 | 核对既有占用、隐含多字、保留区与外部映射；未知范围不视为空闲 |
| mitsubishi-mode-review | 审查模式、暂停、报警和复位 | 按工艺判据检查优先级、保持状态、非预期重启及输出控制 |
| mitsubishi-scenario-tests | 设计或执行正常、异常和恢复验收 | 从要求独立得到预期，校对握手、时基、采样及失败收尾 |

```python
gx_skill_list()
gx_skill_read(name="mitsubishi-io-planner")
```

目录只返回名称与短描述，普通任务不加载无关正文。读取接口只接受三个登记名称，返回正文、版本与 SHA256，不接受任意文件路径，也不执行技能内容。

三项技能的打包源在 `src/gxworks2_mcp/data/skills/`，随 Python wheel 交付，其他 MCP 客户端也能通过上述工具读取。它们并非三个额外的自动编程引擎；规划和审查结论仍由 AI 结合本题需求及实际工具证据完成。

## 项目技能部署

当前聊天工作区的 `.agents/skills/` 已安装五项技能。新一轮任务可发现项目技能；已连接的旧 MCP 服务需重连后取得新增工具。没有修改全局技能目录或重启客户端。

两项上游技能仅用于相应开发工作：

- [mcp-builder](https://github.com/anthropics/skills/tree/dbd4588f9e1033efb41dad4bef2f7947c8993d44/skills/mcp-builder)：来源 Anthropic，固定提交 `dbd4588f9e1033efb41dad4bef2f7947c8993d44`。适用于 MCP 接口开发，沿用本项目 Python 实现；原生调用接口已知时不重新泛化调研。
- [systematic-debugging](https://github.com/obra/superpowers/tree/2ce8aa15d05bd57213e6f746f953aafb7ded7a8b/skills/systematic-debugging)：固定提交 `2ce8aa15d05bd57213e6f746f953aafb7ded7a8b`。在实际故障时使用根因定位和单一假设验证；保留本次授权、已知环境及可复用的核验结果。

上游许可及文件校验值保存在项目技能目录，来源记录为 `SOURCES.json`。三个项目副本与 MCP 打包源逐字节一致；后续更新须同步并重新核对。其他工作区不会因当前项目安装而被配置新技能。
